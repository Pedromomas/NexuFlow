# Reteste após atualizações de anticheat

O selo interno distingue duas coisas:

- **Revisão documental:** código e regras foram comparados com a política disponível.
- **Teste real em jogo:** sessão manual executada após o patch, sem erro de conexão, alerta ou interação invasiva.

Uma revisão documental não será apresentada como certificação da Riot, Valve, Epic/EAC ou BattlEye. Depois de uma atualização relevante, a meta futura é publicar o resultado em 24–48 horas; até concluir o teste real, o aplicativo deve mostrar “teste pendente”.
