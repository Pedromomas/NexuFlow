# Códigos secretos — NexuFlow 2.1

Cada código libera exatamente uma arte. Os resgates são cosméticos, locais e não alteram BOOST, rede, proteção ou telemetria.

| Código | Recompensa | Animação |
|---|---|---|
| `NEXU-SECRETO-157` | Edição Origem | portal azul/vermelho com o áudio original fornecido |
| `NEXU-RIO-021` | Rio Pulse | varredura urbana azul/vermelha |
| `NEXU-KIWI-021` | Kiwi Signal | crescimento orgânico verde/turquesa |

`RESET-CODIGOS` remove somente os três resgates e retorna ao tema padrão caso uma arte secreta esteja ativa.

O antigo estado da versão anterior é migrado somente para a Edição Origem. Ele nunca libera automaticamente Rio Pulse ou Kiwi Signal.
